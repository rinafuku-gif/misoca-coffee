## 1. プロジェクト概要

### 1.1 サイト名
**三十日珈琲**（みそかこーひー / Misoca Coffee）

### 1.2 コンセプト
**「古くて新しい、みんなの焙煎所。」**

山梨県上野原市にある築300年の古民家を拠点とした、体験型シェアロースタリー。
「三十日（みそか）」＝月の最後の日。コーヒー豆の鮮度が約30日で落ちることと、
「30日に一度、会いに来てほしい」という想いを掛けたブランド名。
ADDress（多拠点生活サービス）との接点から生まれた、コミュニティ型コーヒーブランド。

### 1.3 ターゲットユーザー
| セグメント | 詳細 |
|-----------|------|
| 年齢層 | 25〜45歳 |
| 性別 | 男女不問 |
| 志向 | 非日常体験・ローカルカルチャー・サステナビリティへの関心が高い |
| 行動特性 | 多拠点生活・ワーケーションに興味、体験消費を好む、人とのゆるいつながりを求める |
| 隠れた欲求 | 「自分だけの秘密基地的な場所が欲しい」「コーヒーを通じてまだ見ぬ土地や人と出会いたい」 |

### 1.4 ビジネスゴール（優先順）
1. **焙煎体験・見学の予約獲得**（月8件目標 / 収益の柱）
2. **ケータリング依頼の獲得**（月4件目標 / 高粗利率70-74%）
3. **ブランド認知の向上と来訪促進**
4. **オンラインでのコーヒー豆販売**（単品＋サブスク / 補助的売上）
5. **コミュニティ（ADDress連携）の拡大**

**ナビゲーション優先順位:「体験する → 知る → 買う → つながる」**

### 3.6 画像方針

```
■ フォーマット: WebP優先、フォールバックJPEG
■ 遅延読み込み: loading="lazy" を全画像に適用
■ アスペクト比:
  Hero画像:     16:9（古民家空撮 or 焙煎風景動画）
  商品画像:     1:1（正方形）
  体験写真:     4:3（横長・臨場感重視）
  ブログOGP:   1200x630px

■ 写真方針（※ストックフォト一切不使用）
  - 全て現地（上野原の古民家焙煎所）で撮影した素材のみ
  - 築300年の梁や柱を背景に、自然光が差し込む空間
  - 後藤さん・稲福さんが実際に作業している姿
  - 訪問者が焙煎体験を楽しんでいる様子
  - 上野原の四季の風景（里山・古民家周辺）
  - トーン: 自然光ベース、過度なフィルター不要
    （古民家の空気感をそのまま伝える）

■ 動画（Hero用）
  - 焙煎風景のショートムービー（15-30秒・ループ再生）
  - モバイルでは静止画にフォールバック
  - autoplay / muted / loop / playsinline
```

## 11. レビュー依頼時のチェックポイント

以下の観点でのレビューを依頼します:

1. **情報設計**: 「体験する→知る→買う→つながる」の導線設計は適切か
2. **ブランド一貫性**: コンセプトブックとサイト設計の整合性
3. **UIデザイン**: カラー（枯草色・藍鼠色・紺墨色）・タイポグラフィの妥当性
4. **UX**: CTA配置（焙煎体験予約が最優先）・コンバージョン設計
5. **コンテンツ**: テキスト情報の質・量・トーン（「古民家」「体験」「コミュニティ」軸）
6. **差別化**: PostCoffee・BLUE BOTTLE等の競合と明確に異なるポジショニングが取れているか
7. **技術選定**: フレームワーク・API連携の妥当性とコスト効率
8. **ローカルSEO**: 地域検索での流入施策
9. **アクセシビリティ**: WCAG準拠の設計
10. **収益導線**: 焙煎体験予約・ケータリング問い合わせへの導線は十分か
