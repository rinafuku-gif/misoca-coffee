## 1. プロジェクト概要

### 1.1 サイト名
**Misoca Coffee**（ミソカコーヒー）

### 1.2 コンセプト
「毎月の晦日（みそか）に届く、こだわりのコーヒー体験」
月末のご褒美として、厳選されたスペシャルティコーヒーをサブスクリプションで届けるD2Cブランドサイト。

### 1.3 ターゲットユーザー
| セグメント | 詳細 |
|-----------|------|
| 年齢層 | 25〜45歳 |
| 性別 | 男女不問 |
| 志向 | 品質重視・サステナビリティへの関心が高い |
| 行動特性 | 自宅でコーヒーを楽しむ、サブスク利用に抵抗がない |

### 1.4 ビジネスゴール
- サブスクリプション会員の獲得（月額制コーヒー定期便）
- ブランド認知の向上
- 単品購入によるスポット売上

## 2. サイトマップ

```
/                          ... トップページ（Hero + 主要セクション）
├── /about                 ... ブランドストーリー・こだわり

│   └── /menu/:id          ... 個別商品詳細
├── /subscription          ... サブスクリプションプラン紹介
├── /blog                  ... コラム・ニュース
│   └── /blog/:slug        ... 記事詳細
├── /contact               ... お問い合わせフォーム
├── /faq                   ... よくある質問
├── /privacy               ... プライバシーポリシー
├── /terms                 ... 利用規約
└── /tokushoho             ... 特定商取引法に基づく表記
```

### 3.6 画像方針

```
■ フォーマット: WebP優先、フォールバックJPEG
■ 遅延読み込み: loading="lazy" を全画像に適用
■ アスペクト比:
  Hero画像:     16:9
  商品画像:     1:1（正方形）
  ブログOGP:   1200x630px
■ 写真トーン:
  - 暖色系フィルター（温かみのある雰囲気）
  - 自然光を活かした撮影イメージ
  - 背景はウッド調・リネン素材
```

## 10. 改善レビュー依頼時のチェックポイント

以下の観点でのレビューを依頼します:

1. **情報設計**: サイトマップ・ページ構成は適切か
2. **UIデザイン**: カラー・タイポグラフィ・コンポーネント設計の妥当性
3. **UX**: ユーザー導線・CTA配置・コンバージョン設計
4. **コンテンツ**: テキスト情報の質・量・トーン
5. **技術選定**: フレームワーク・ツールの選定は妥当か
6. **SEO**: 検索エンジン最適化の設計
7. **アクセシビリティ**: WCAG準拠の設計
8. **パフォーマンス**: 表示速度の設計目標
9. **モバイル対応**: レスポンシブ設計の方針
10. **セキュリティ**: 決済・個人情報保護の設計
