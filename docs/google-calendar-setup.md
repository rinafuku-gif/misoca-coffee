# Google Calendar APIセットアップ手順

> **このガイドは非技術者向けです。Ryoが一人で完結できるように、難しい言葉は避けました。**
> 
> 所要時間: 約10分
> 難易度: やさしい（クリックとコピペだけ）

---

## この手順で何ができるようになるか

三十日珈琲の「焙煎体験予約」カレンダーを自動で管理できるようになります。
チームが予約ページから予約があると、自動でカレンダーに反映される仕組みです。

---

## 事前準備: 焙煎体験予約カレンダーを作成する

Google Calendar（カレンダー）に新しいカレンダーを1つ作ります。これが予約の管理台帳になります。

### 1. Googleカレンダーを開く

**misocacoffee@gmail.com** でGoogleカレンダーにログイン
- URL: https://calendar.google.com

### 2. 新しいカレンダーを作成

左メニューの **「他のカレンダー」** セクションを見つけて、その横の **「+」ボタン** をクリック

メニューが出たら **「新しいカレンダーを作成」** を選択

### 3. カレンダーの名前を入力

以下を入力してください：

```
焙煎体験予約
```

その他の設定はデフォルトで大丈夫です。**「作成」** をクリック

これで完了です。カレンダー一覧に「焙煎体験予約」が追加されました。

---

## ステップ1: Google Cloud Consoleでプロジェクトを作成

Google Cloud Console は、Googleのサービスを管理する「操作パネル」のようなものです。
ここで設定することで、チームのアプリとカレンダーが連携できるようになります。

### 1. Google Cloud Consoleにログイン

**misocacoffee@gmail.com** でこのURL を開いてください：

```
https://console.cloud.google.com/
```

### 2. プロジェクトを選択する

画面の上の方（ナビゲーションバー）に **「プロジェクトを選択」** というボタンがあります。クリック

### 3. 新しいプロジェクトを作成

右上の **「新しいプロジェクト」** ボタンをクリック

### 4. プロジェクト名を入力

入力欄に以下を入力してください：

```
misoca-coffee-calendar
```

その他の項目は何も触らず、**「作成」** をクリック

プロジェクトが作成されるまで数秒待ちます。

---

## ステップ2: Google Calendar APIを有効化

API（アプリケーション・プログラミング・インターフェース）は、簡単に言うと
「Googleのサービスとアプリを繋ぐ通信路」です。

Calendar APIを有効にすることで、チームのアプリがカレンダーに予約を書き込めるようになります。

### 1. APIライブラリを開く

左メニューから **「APIとサービス」** → **「ライブラリ」** をクリック

### 2. Google Calendar APIを検索

上の検索欄に以下を入力してください：

```
Google Calendar API
```

### 3. APIを有効にする

Google Calendar APIが出てきたら、それをクリック

画面上の **「有効にする」** ボタンをクリック

有効化が完了するまで数秒待ちます。（ページが切り替わります）

---

## ステップ3: サービスアカウントを作成

サービスアカウント は「Ryoの代わりにカレンダーを操作する専用の人（ボット）」だと思ってください。
この設定により、チームのアプリが自動でカレンダーに予約を書き込めます。

### 1. 認証情報を作成する

左メニューから **「APIとサービス」** → **「認証情報」** をクリック

画面上の **「認証情報を作成」** をクリック

### 2. サービスアカウントを選択

プルダウンメニューから **「サービスアカウント」** を選択

### 3. サービスアカウント名を入力

入力欄に以下を入力してください：

```
calendar-bot
```

「サービスアカウントの説明」は空欄で大丈夫です。

**「作成して続行」** をクリック

### 4. ロール選択はスキップ

次の画面で「このサービスアカウントに付与するロール」を選ぶところが出ていますが、
このステップでは不要です。**「続行」** をクリックしてスキップしてください。

### 5. 完了

**「完了」** をクリック

これでサービスアカウント「calendar-bot」が作成されました。

---

## ステップ4: 秘密鍵（JSONファイル）をダウンロード

秘密鍵 は、チームのアプリがカレンダーを操作するための「パスポート」です。
これをダウンロードして、チームに共有します。

### 1. 作成したサービスアカウントをクリック

認証情報ページに「calendar-bot」が表示されているはずです。クリック

### 2. キータブを開く

画面上の **「キー」** タブをクリック

### 3. 新しいキーを作成

**「鍵を追加」** ボタンをクリック

メニューから **「新しい鍵を作成」** を選択

### 4. JSON形式を選択

ポップアップで **「JSON」** を選択してクリック

**「作成」** をクリック

### 5. ファイルをダウンロード

JSONファイルが自動的にダウンロードされます。

ファイル名は長くて複雑ですが、これが秘密鍵です。大切に保管してください。

---

## ステップ5: カレンダーにボットを招待する

サービスアカウント（calendar-bot）にカレンダーを編集する権限を付与します。

### 1. Googleカレンダーに戻る

Google Calendar を開いてください：

```
https://calendar.google.com/
```

### 2. 「焙煎体験予約」カレンダーの設定を開く

左メニューの「焙煎体験予約」の横にある **3点メニュー（・・・）** をクリック

**「設定」** を選択

### 3. 「特定のユーザーまたはグループと共有する」セクションを開く

設定ページを下にスクロールしていくと、**「特定のユーザーまたはグループと共有する」** というセクションがあります。

### 4. ユーザーを追加する

**「ユーザーやグループを追加」** をクリック

### 5. calendar-botのメールアドレスを入力

ダウンロードしたJSONファイルを開いてください。
（メモ帳やテキストエディタで開けます）

ファイル内で **「client_email」** を探してコピーしてください。

例：
```
calendar-bot@misoca-coffee-calendar.iam.gserviceaccount.com
```

このメールアドレスをカレンダー設定の入力欄に貼り付けます。

### 6. 権限を設定

**「予定の変更」** を選択してください。

**「送信」** をクリック

これでcalendar-botにカレンダーの編集権限が与えられました。

---

## ステップ6: チームに必要な情報を共有

以下の3つの情報をチームに共有すれば、設定完了です。

ダウンロードしたJSONファイルをテキストエディタで開いて、以下をコピーしてください：

### 必要な情報

1. **client_email**
   - 例：`calendar-bot@misoca-coffee-calendar.iam.gserviceaccount.com`

2. **private_key**
   - 長い文字列が囲まれています。全部コピーしてください。
   - 例：`-----BEGIN PRIVATE KEY-----\nMIIEvQIB...`

3. **カレンダーID**
   - Google Calendarの「焙煎体験予約」設定から確認できます
   - 設定ページを下にスクロールして、**「カレンダーの統合」** セクションで見つかります
   - 例：`abc123def456@group.calendar.google.com`

### JSONファイルは削除OK

3つの情報をチームに共有したら、ダウンロードしたJSONファイルは削除してしまってOKです。
（セキュリティのため、機器に残す必要はありません）

## 予約可能枠の登録方法

カレンダーに「予約可能な時間枠」を追加すると、予約ページにそれが反映されます。

### カレンダーに予定を追加する

Google Calendarを開いて、「焙煎体験予約」カレンダーに予定を追加します。

### 予約可能枠の形式

以下のルールで入力してください：

| 項目 | ルール |
|------|--------|
| **タイトル** | 以下の3パターンから選んでください（コピペOK）|
| | `予約可能｜プライベート` |
| | `予約可能｜グループ` |
| | `予約可能｜出張` |
| **時間帯** | 90分固定 |
| **例** | 4月15日 10:00〜11:30 「予約可能｜プライベート」 |

### 予約区分の意味

- **プライベート** = 個人向け焙煎体験（1〜2名）
- **グループ** = グループ向け体験（3名以上）
- **出張** = 外部ケータリング対応可能な時間帯

## トラブル対策

### Q: JSONファイルがダウンロードされない

→ ブラウザの設定でダウンロードがブロックされている可能性があります。
ブラウザの通知をチェックするか、Chrome/Safari/Firefoxの設定を確認してください。

### Q: 「権限がない」というエラーが出た

→ ステップ5でcalendar-botにカレンダーを共有できていない可能性があります。
もう一度ステップ5を確認して、権限が「予定の変更」になっているか確認してください。

### Q: チームから「接続できない」と言われた

→ client_email と private_key が正しくコピーされているか確認してください。
JSONファイルの内容を再度チームに共有してください。

## まとめ

- **焙煎体験予約** カレンダーをGoogleカレンダーに作成
- Google Cloud Consoleでプロジェクトとサービスアカウント を作成
- Calendar APIを有効化し、秘密鍵をダウンロード
- calendar-botにカレンダーの編集権限を付与
- 3つの情報（client_email, private_key, カレンダーID）をチームに共有

これで自動予約管理システムが完成します。
